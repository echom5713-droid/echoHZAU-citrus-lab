# Citrus Essential Oil Inquiry — Teaching Project

[Teaching demonstration website](http://43.132.224.207/) · [Separate scientific engineering website](http://43.132.224.207:8080/)

The teaching website presents citrus essential oil inquiry through micro-lessons, student and teacher demonstrations, visualisations and teaching resources.

## Source and website

This repository preserves an earlier Next.js, React and Supabase implementation of the citrus-extraction teaching/data project. The current teaching website has evolved beyond this source version; this repository is not an exact snapshot of its deployed code.

The separate [EchoClass Scientific project](https://github.com/echom5713-droid/echoclass-scientific) focuses on scientific record provenance, sealed analysis inputs and reproducible Python calculations. Its website is available at [http://43.132.224.207:8080/](http://43.132.224.207:8080/).
